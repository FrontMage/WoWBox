# WoW Box 预览版功能清单

本清单跟踪面向标准包 `com.winlator.llm` 的功能整合与验证。状态必须依据本版源码和最终 APK 的证据填写，旧设备 APK 的结果不能替代本版验收。

| 功能或修复 | 本版目标 | 最终状态与验证 |
| --- | --- | --- |
| Battle.net → WoW GUI 启动 | 通过原有 Wine 路线启动，不使用战网 relay | NOVA 登录战网并启动泰坦服，游戏渲染至登录界面；试玩账号无游戏时间，未验证进入世界或长期稳定性。Thor 未测 |
| 中文字体 | 使用可公开分发的字体资源 | NOVA 战网页面部分中文显示方框，游戏登录画面中文正常；原因待查 |
| Wine / FEX 主线 | 使用本版构建记录中的统一 Proton 固定版本 | 固定输入、干净构建、资源哈希和模拟器升级验证通过；NOVA 短时启动通过，不代表其他设备验收 |
| MapleStory 兼容修复 | 随统一 Wine 主线提供 | 标准包无一键入口；本版游戏运行未验证 |
| Wine 内置 DLL 恢复 | 从当前运行时恢复，不回拷旧版缓存 | 测试覆盖旧缓存和恢复中断；最终版设备完整回归待验证 |
| 触屏、手柄和键鼠 | 保留已有标准包交互功能 | 待本版回归 |
| 可选帧生成 | 默认关闭，用户自行导入授权 DLL | 待本版回归 |
| XR / VR 入口 | 暂时关闭 | 多进程会话与运行时升级尚未完成同步及设备验证 |
| RenderDoc | 暂不提供标准包入口 | 内部 UU 诊断能力尚未迁移及验收 |
| 内部 UU 相关功能 | 评估可移植的功能；UU 包身份专属行为不作为标准包行为 | 待功能盘点 |
| 新装和旧公开版升级 | 保留可识别的用户数据与运行时一致性 | 最终版隔离模拟器从 v0.1 升级通过，测试数据及设置保留；NOVA 隔离用户新装并启动，设备旧版升级待验证 |

发布前将每项替换为实际结论及证据；无法覆盖的功能应保留“未验证”，不能写成通过。

标准包禁用旧版调试 API 的单层安装、选择和前缀重整入口，避免绕过整体升级事务；正常界面安装、完整升级、只读预检、启动及停止不受此限制。其他包身份不受此规则影响。完整战网安装器、旧 DLL 缓存设备回归及 Thor 验收仍待完成。继承运行库的对应源码和许可来源尚待核实，不应发布这些运行资源。
