# WoW Box v0.3.0 功能与验证状态

本表区分已观察到的诊断结果与最终标准包验收。红魔诊断包使用独立包名、数据目录和构建配置，其结果不能自动推广到标准 `com.winlator.llm` 或其他设备。

| 功能或问题 | 本版状态与验证范围 |
| --- | --- |
| 红魔图形驱动 | `NX809J / SM8850` 的诊断包使用 Turnip Gen8 V39，用户确认战网登录页的彩色条纹消失。该手机上的标准包测试副本完成从 0.2 到 0.3 候选的升级、9/9 层校验和两次各 20 秒的 TestD3D 绘制；第二次确认进程映射 V39。测试范围不代表最终标准 APK 的 WoW 或长期验收，也不推定其他 8xx 的兼容性。 |
| 宿主 Vulkan 合成 | 诊断包组合 V39、Vulkan 宿主合成和两个缓存参数后，用户确认 WoW Forever 1.60.1.70862 的一个 **D3D12** 场景黑块消失；这不确定单一原因，D3D11、其他场景和长期稳定性未验收。 |
| D3D11 / D3D12 缓存默认值 | 配置代码为 DXVK 和 VKD3D 提供 `vic`、`force_host_cached`，保留显式覆盖。红魔诊断游戏进程的两个环境变量已核对；设备差异和性能收益不能由此推定。 |
| 战网 CEF 参数 | 红魔诊断包的 `--js-flags=--no-incremental-marking` 已确认到达 renderer 子进程，但用户仍报告战网窗口闪退，后续日志也曾记录 renderer 重启；它是尝试缓解而非确认修复。 |
| WoW 闪退与 CPU 频率 | 用户报告 WoW 也曾闪退，现有一次执行访问异常与容器退出几乎同时发生，原因未确定。用户另报告 CPU 频率波动伴随明显卡顿，短时采样未确立因果。 |
| Wine / FEX | 沿用 `v0.2.0-preview` 的 Wine/FEX 运行时；Android `RtlWaitOnAddress` 补丁尚未打包、受管注册或实机验证，不应算成本版修复。 |
| 新安装和升级 | 同一红魔上的 0.2 测试副本升级到最终 0.3 APK 后，spec、state、自定义 DXVK 覆盖及测试文件均保留；同机全新安装也通过预检及中性 D3D9 测试。前一候选模拟 V39 资源冲突时，校验旧 GPU 后回退并完成 20 秒 TestD3D；恢复 V39 后 preflight ready。其他旧版、机型和正式游戏升级仍未验收。 |
| 中文字体、输入和可选帧生成 | 保留现有公开路径；本版最终 APK 的完整交互、插件、帧生成与其他机型回归尚未完成。 |
| 来源与许可证 | V39 二进制及封装哈希已记录，完整对应源码和补丁未核实；继承 imagefs 仍有源码与许可来源缺口，详见 `THIRD_PARTY_NOTICES.md`。 |

设备检查、源码编译和测试结果分别记录，不能把短场景成功当作普通版全面验收。标准包保留原有调试 API 保护与用户前缀保护策略。
